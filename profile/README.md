# BloomCode

Interview practice for engineers who already program. Every exercise is original, comes with its own test, and has a worked solution you can check against when you are done.

**New here? Start at [bloomcode.github.io](https://bloomcode.github.io/).** It says which track to pick, which exercises to do first and later, and links every guide, workbook, answer key and starter.

## Start

1. Open a starter above and click **Use this template** → **Create a new repository**.
2. Clone it and run `make test EX=1.1`. The test fails until you write exercise 1.1.
3. Write the code, make the test pass, push. Your `PROGRESS.md` ticks off every exercise that passes.

The workbook for your language explains each exercise; the answer key shows a tested solution, blurred until you reveal it.

## Found a problem?

Open an issue on the starter you are working in: a test that rejects a correct answer, an unclear prompt, a broken page. See [CONTRIBUTING](https://github.com/bloomcode/.github/blob/main/CONTRIBUTING.md).
